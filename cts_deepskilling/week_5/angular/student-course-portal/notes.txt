Angular Project File Notes
===========================
angular.json         - Workspace configuration: build targets, file paths, budget thresholds, serve config
tsconfig.json        - Root TypeScript compiler options shared by app and test configs
tsconfig.app.json    - TypeScript config specific to the application build (extends tsconfig.json)
package.json         - npm dependencies, devDependencies, and CLI scripts (ng serve, ng build, ng test)
src/main.ts          - Application entry point: bootstraps AppComponent with appConfig
src/app/app.config.ts - Standalone app config: providers for router, HttpClient, NgRx store, interceptors
src/app/app.component.ts - Root component: hosts <app-header> and <router-outlet>
src/index.html       - Shell HTML page: contains <app-root> where Angular bootstraps into the DOM

budgets in angular.json:
  maximumWarning - Build warns when bundle size exceeds this threshold
  maximumError   - Build fails when bundle size exceeds this threshold

JSON Server for mock API:
  json-server --watch src/assets/db.json --port 3000

Redux DevTools:
  Install "Redux DevTools" Chrome extension to inspect NgRx state, actions, and time-travel debug
